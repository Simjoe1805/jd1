# Distance to Jules

**Live site:** https://simjoe1805.github.io/jd1/

## Project Vision
Distance to Jules is an interactive web experience built as a visual expression of longing, sadness, and love across distance.
The user moves through a first person style sequence of scenes, clicking through moments that represent what it feels like to be far away from Jules.
The goal is emotional clarity: to help Jules feel what words alone cannot fully explain.

## Experience Summary
The site acts like a short, playable emotional story.

1. The user enters a quiet opening scene that sets the mood.
2. Each click moves to a new "memory-space" or symbolic environment.
3. Motion, transitions, sound, and text fragments build emotional tension.
4. The journey ends with a direct message to Jules.

## Core Emotional Themes
- Distance
- Longing
- Memory
- Silence
- Hope

## MVP Scope
- Click based scene progression
- 4 to 7 narrative scenes
- First person perspective illusion using layered visuals and parallax
- Ambient animation in each scene
- Short text overlays or voice lines
- Final dedication scene to Jules
- Mobile and desktop support

## Build Direction
- Keep interactions simple and emotional, not game-mechanic heavy
- Prioritize atmosphere over complexity
- Use smooth scene transitions to mimic memory shifts
- Use visuals and pacing to communicate feelings with minimal text

## Success Criteria
The project is successful if a visitor can finish the experience and clearly understand:

1. The pain of being far away from Jules.
2. The depth of care and emotional presence behind that pain.
3. The intended message of connection, even across distance.
